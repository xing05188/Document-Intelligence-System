# 部署指南（systemd 服务）

## 1. 安装依赖

```bash
# 安装 Python 虚拟环境 & Nginx
sudo apt update
sudo apt install -y python3-venv nginx

# 进入项目
cd /home/document/Document-Intelligence-System
```

## 2. 后端部署

```bash
# 激活已有的虚拟环境 myenv（位于上级目录）
source /home/document/myenv/bin/activate

# 安装依赖
pip install -r requirements.txt

# 数据库迁移（创建表）
python scripts/migrate_and_validate_db.py
```

### 创建 systemd 服务

```bash
sudo tee /etc/systemd/system/doc-intel-backend.service << 'EOF'
[Unit]
Description=Document Intelligence System - Backend
After=network.target

[Service]
Type=simple
User=document
Group=document
WorkingDirectory=/home/document/Document-Intelligence-System/src
Environment="PATH=/home/document/myenv/bin"
ExecStart=/home/document/myenv/bin/python -m uvicorn api.main:app --host 0.0.0.0 --port 8001
Restart=on-failure
RestartSec=5
StandardOutput=journal
StandardError=journal

[Install]
WantedBy=multi-user.target
EOF
```

```bash
# 重新加载 systemd，启用并启动服务
sudo systemctl daemon-reload
sudo systemctl enable doc-intel-backend
sudo systemctl start doc-intel-backend

# 查看状态
sudo systemctl status doc-intel-backend
```

## 3. 前端部署（外网可访问）

```bash
cd /home/document/Document-Intelligence-System/frontend

# 安装依赖
npm install
```

修改 `frontend/vite.config.js`，将 `host` 改为 `'0.0.0.0'`：

```js
export default defineConfig({
  plugins: [vue()],
  server: {
    host: '0.0.0.0',         // 允许外部访问
    port: 5174,
    strictPort: true,
    proxy: {
      '/api': {
        target: 'http://localhost:8001',
        changeOrigin: true,
        ws: true,
      },
    },
  },
})
```

### 创建 systemd 服务

```bash
sudo tee /etc/systemd/system/doc-intel-frontend.service << 'EOF'
[Unit]
Description=Document Intelligence System - Frontend
After=network.target doc-intel-backend.service
Wants=doc-intel-backend.service

[Service]
Type=simple
User=document
Group=document
WorkingDirectory=/home/document/Document-Intelligence-System/frontend
ExecStart=/usr/bin/npm run dev
Restart=on-failure
RestartSec=5
StandardOutput=journal
StandardError=journal

[Install]
WantedBy=multi-user.target
EOF
```

```bash
# 重新加载 systemd，启用并启动服务
sudo systemctl daemon-reload
sudo systemctl enable doc-intel-frontend
sudo systemctl start doc-intel-frontend

# 查看状态
sudo systemctl status doc-intel-frontend
```

## 6. （可选）Nginx 反向代理（单端口 80 访问）

```nginx
server {
    listen 80;
    server_name 150.158.194.75;

    location /api {
        proxy_pass http://127.0.0.1:8001;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_buffering off;
        proxy_read_timeout 300s;
    }

    location / {
        proxy_pass http://127.0.0.1:5174;
        proxy_set_header Host $host;
    }
}
```

```bash
sudo ln -s /etc/nginx/sites-available/doc-intel /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
```

## 环境变量说明

| 变量 | 说明 | 是否必填 |
|------|------|----------|
| `LLM_PROVIDER` | LLM 提供商（deepseek / zhipu / modelscope） | ✅ |
| `DEEPSEEK_API_KEY` / `ZHIPU_API_KEY` | LLM API 密钥 | ✅ |
| `DATABASE_URL` | Supabase / PostgreSQL 连接串 | ✅（启用 DB 时） |
| `SUPABASE_URL` | Supabase 项目 URL | ✅（启用 Storage 时） |
| `SUPABASE_SERVICE_KEY` | Supabase 服务角色密钥 | ✅（启用 Storage 时） |
| `AUTH_SECRET_KEY` | JWT 签名密钥 | ✅（生产环境务必修改） |

## 维护命令

```bash
# 查看后端日志
sudo journalctl -u doc-intel-backend -f

# 查看前端日志
sudo journalctl -u doc-intel-frontend -f

# 重启后端
sudo systemctl restart doc-intel-backend

# 重启前端
sudo systemctl restart doc-intel-frontend

# 同时重启前后端
sudo systemctl restart doc-intel-backend doc-intel-frontend

# 停止服务
sudo systemctl stop doc-intel-backend doc-intel-frontend

# 更新代码后重启
cd /home/document/Document-Intelligence-System
git pull
sudo systemctl restart doc-intel-backend
# 若前端依赖有变化还需 npm install
cd frontend && npm install && sudo systemctl restart doc-intel-frontend
```
