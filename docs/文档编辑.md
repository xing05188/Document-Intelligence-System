# 文档编辑模式 — 完整调研报告

## 一、概述

文档编辑模式是系统的核心功能之一，通过 **Agent A**（`AgentA`）实现。用户以自然语言描述编辑需求，系统解析指令后生成动作计划（ActionPlan），由对应格式的适配器（Adapter）逐动作执行编辑，最终生成编辑后的文档。

**核心流程：**
1. 用户输入自然语言编辑指令
2. `instruction_parser.py` 解析指令（LLM 优先 + 规则回退）
3. 生成标准化的 `ActionPlan`（动作计划）
4. `capability_matrix.py` 校验动作与文件类型兼容性
5. 对应格式的 Adapter 逐动作执行编辑
6. 保存编辑后的文件到输出路径

---

## 二、功能特性总览

| 特性类别 | 具体功能 |
|---------|---------|
| **内容编辑** | 文本查找替换、段落重排、内容提取、删除空行 |
| **样式设置** | 字体族、字号、字体颜色、加粗、斜体、下划线、高亮 |
| **段落格式** | 对齐方式、行距、段前/段后间距、首行缩进、底纹、边框 |
| **标题处理** | 标题加粗、标题编号、目录插入 |
| **列表处理** | 项目符号列表、编号列表 |
| **表格处理** | 批量格式化、自动列宽、冻结表头、行重排、内容提取 |
| **页眉页脚** | 插入页码、插入页脚文本 |
| **超链接** | 添加超链接 |
| **文档结构** | 插入表格、统一样式、批量格式化 |

## 三、支持的文档格式

| 格式 | 扩展名 | Adapter 类 | 底层库 | 能力级别 |
|-----|--------|-----------|--------|---------|
| Word | `.docx` | `DocxAdapter` | `python-docx` | 完整支持（27 种动作） |
| Markdown | `.md` | `MdAdapter` | 正则+字符串处理 | 部分支持（6 种动作） |
| Excel | `.xlsx` | `XlsxAdapter` | `openpyxl` | 部分支持（7 种动作） |
| 纯文本 | `.txt` | `TxtAdapter` | 正则+字符串处理 | 部分支持（6 种动作） |

> 注：`FileType` 枚举中还定义了 `pdf`、`xls`、`csv`、`doc` 格式，但这些格式在**文档编辑模式**中暂未实现 Adapter，当前仅作为上传和识别的类型存在。

## 五、各格式支持的编辑操作详解

### 5.1 DOCX（Word 文档）– 完整支持

**Adapter:** `DocxAdapter`（基于 `python-docx`）

#### 5.1.1 文本内容操作

| 操作 | 动作类型 | 说明 |
|------|---------|------|
| 文本查找替换 | `replace_text` | 支持段落内和表格单元格内的查找替换；优先在 Run 级别替换以保留样式，跨 Run 时回退到段落级替换 |
| 段落重排 | `reorder_paragraphs` | 按段落索引移动段落；禁止跨标题块移动；自动识别标题块边界 |
| 内容提取 | `extract_content` | 提取标题、正文段落、表格；支持 LLM 语义标题识别 |
| 删除空行 | `remove_blank_lines` | 删除文档中的空段落 |

#### 5.1.2 标题操作

| 操作 | 动作类型 | 说明 |
|------|---------|------|
| 标题加粗 | `bold_heading` | 按标题级别加粗；自动包含文档总标题；支持样式标题和语义标题 |
| 标题自动编号 | `set_heading_numbering` | 为标题添加自动编号（如"第1章"、"1.1"等格式） |
| 插入目录 | `insert_toc` | 在文档开头插入目录；已存在目录时跳过；支持 LLM 构建上下文目录 |

#### 5.1.3 字体样式

| 操作 | 动作类型 | 说明 |
|------|---------|------|
| 设置字体族 | `set_font_family` | 设置字体（如宋体、黑体、Times New Roman 等） |
| 设置字号 | `set_font_size` | 设置字体大小（磅值 Pt） |
| 设置字体颜色 | `set_font_color` | 设置字体颜色（Hex 值或中文颜色名） |
| 加粗 | `bold_heading` 内含 | 对指定内容应用粗体 |
| 斜体 | `set_italic` | 对文本应用斜体格式 |
| 下划线 | `set_underline` | 对文本应用下划线格式 |
| 高亮标记 | `set_highlight` | 为文本添加黄色高亮标记 |

#### 5.1.4 段落格式

| 操作 | 动作类型 | 说明 |
|------|---------|------|
| 设置对齐方式 | `set_paragraph_alignment` | 左对齐、居中、右对齐、两端对齐 |
| 设置行距 | `set_line_spacing` | 设置行间距（1.0、1.5、2.0 倍等） |
| 设置段前/段后间距 | `set_paragraph_spacing` | 设置段落前后的空白距离（磅值） |
| 设置首行缩进 | `set_first_line_indent` | 设置段落首行缩进（如 2 字符） |
| 段落底纹 | `set_paragraph_shading` | 为段落设置背景底纹色（RGB） |
| 段落边框 | `set_paragraph_border` | 为段落添加边框（上下左右） |

#### 5.1.5 列表操作

| 操作 | 动作类型 | 说明 |
|------|---------|------|
| 项目符号列表 | `set_bullet_list` | 将段落转换为项目符号列表 |
| 编号列表 | `set_numbered_list` | 将段落转换为编号列表 |

#### 5.1.6 表格操作

| 操作 | 动作类型 | 说明 |
|------|---------|------|
| 插入表格 | `insert_table` | 在指定位置插入表格，支持表头加粗 |
| 批量格式化 | `batch_format` | 批量设置单元格字体、对齐、边框等 |

#### 5.1.7 页面元素

| 操作 | 动作类型 | 说明 |
|------|---------|------|
| 插入页码 | `insert_page_number` | 在页脚插入页码域，支持左/中/右对齐 |
| 插入页脚文本 | `insert_footer_text` | 在页脚插入自定义文本 |
| 添加超链接 | `add_hyperlink` | 添加 URL 超链接或内部书签链接 |
| 统一样式 | `unify_style` | 统一全文字体、段落间距、对齐等样式，支持预设模板 |

### 5.2 MD（Markdown）– 部分支持

**Adapter:** `MdAdapter`（基于正则表达式和字符串处理）

| 操作 | 动作类型 | 说明 |
|------|---------|------|
| 标题加粗 | `bold_heading` | 将指定级别的 Markdown 标题文本加粗（`**标题**`） |
| 统一样式 | `unify_style` | 统一标题层级、列表符号风格（统一为 `-`）、规范标题/列表前后空行 |
| 段落重排 | `reorder_paragraphs` | 按段落块进行重排；自动锁定前缀（总标题/元信息块）防止被移动 |
| 文本替换 | `replace_text` | 全文文本查找替换 |
| 内容提取 | `extract_content` | 提取标题列表、段落块、字段值（支持 `key: value` 格式） |
| 删除空行 | `remove_blank_lines` | 将连续 3 行以上空行规范为 2 行 |
| 插入目录 | `insert_toc` | 基于标题层级生成目录列表 |
| 插入表格 | `insert_table` | 转换为 Markdown 表格格式 |
| 标题编号 | `set_heading_numbering` | 为标题添加内容前缀编号 |
| 斜体 | `set_italic` | 应用斜体格式（`*text*` 或 `_text_`） |
| 项目符号列表 | `set_bullet_list` | 使用 `-` 或 `*` 创建列表 |
| 编号列表 | `set_numbered_list` | 使用 `1.` `2.` 等创建编号列表 |
| 添加超链接 | `add_hyperlink` | 添加 `[text](url)` 格式超链接 |

**不支持的操作（需转为 docx 后处理）：** 插入页码、字体族/字号/颜色、段落对齐、行距、首行缩进、下划线、高亮、段落底纹/边框、页脚文本

---

### 5.3 XLSX（Excel 表格）– 部分支持

**Adapter:** `XlsxAdapter`（基于 `openpyxl`）

#### 5.3.1 单元格操作

| 操作 | 动作类型 | 说明 |
|------|---------|------|
| 批量格式化 | `batch_format` | 批量设置单元格字体、对齐、边框、列宽；支持指定范围 |
| 统一样式 | `unify_style` | 统一工作表字体、对齐、边框样式；支持表头/正文区分设置 |
| 文本替换 | `replace_text` | 在单元格文本中进行查找替换 |
| 内容提取 | `extract_content` | 提取表格字段数据 |

#### 5.3.2 行列操作

| 操作 | 动作类型 | 说明 |
|------|---------|------|
| 自动列宽 | `auto_column_width` | 根据内容自动调整列宽 |
| 冻结表头 | `freeze_header_row` | 冻结首行/表头行 |
| 行重排 | `reorder_paragraphs` | 对行进行排序或区域重排 |

**不支持的操作：** 标题加粗、插入页码/目录、段落格式（对齐/行距/缩进）、列表、页脚、超链接等（Excel 本身非文档排版类格式）

---

### 5.4 TXT（纯文本）– 部分支持

**Adapter:** `TxtAdapter`（基于正则表达式和字符串处理）

| 操作 | 动作类型 | 说明 |
|------|---------|------|
| 段落重排 | `reorder_paragraphs` | 按段落块重排；自动锁定前缀（标题/元信息）；支持自然语言"移动到第 N 段之后"语义 |
| 文本替换 | `replace_text` | 全文文本查找替换 |
| 内容提取 | `extract_content` | 提取段落块和字段值（支持 `key: value` 格式） |
| 删除空行 | `remove_blank_lines` | 将连续 3 行以上空行规范为 2 行 |
| 统一样式 | `unify_style` | 文本级规范化（去除多余空格、规范空行） |
| 段落拆分 | `split_paragraphs` | 将文本按空行或非空行拆分段落块 |

**不支持的操作：** 标题加粗、页码、字体样式、段落对齐/行距/缩进、表格、列表、页脚、底纹/边框等所有样式类操作

## 六、指令解析机制

### 6.1 解析流程

```
用户指令 -> LLM 优先解析（2 次重试） -> 合法 JSON? -> 是 -> 规则引擎一致性校验 -> 输出 ActionPlan
                                              |
                                              -> 否 -> 规则引擎解析 -> 命中? -> 是 -> 输出 ActionPlan
                                                                      |
                                                                      -> 否 -> 人工确认回退
```

## 九、使用示例

### 自然语言指令示例

```
# 文字样式
"把标题加粗"
"字体改为宋体，字号设为12磅"
"把正文颜色改为红色"
"设置标题为斜体"
"给关键词加下划线"

# 段落格式
"把所有段落设为两端对齐"
"设置1.5倍行距"
"首行缩进2字符"
"段前间距设为12磅"

# 内容操作
"把第三段移到第一段之后"
"把'旧文本'替换为'新文本'"
"提取所有标题和日期"
"删除所有空行"

# 文档结构
"插入目录"
"在文档开头插入一个3列5行的表格"
"插入页码，居中"

# 综合操作
"1. 统一全文样式 2. 标题加粗 3. 插入页码"
"把文档格式调整为标准的学术论文格式"
```
